### 20261102｜DOMINO 三结构域 Benchmark 阶段性结果

**本周工作：**

在此前三结构域 AB→C 检索 Benchmark 的基础上，进一步完善数据筛选流程，引入训练来源同源筛查，并对两种 Training-free 方法（Additive Embedding Fusion 与 DOMO-based Generative Fusion）进行重新评测。同时，利用 AlphaFold 3 对两种方法检索得到的第三结构域进行结构质量评价。

**当前发现的核心问题：**

按照原先的实验预期，经过更严格的数据筛选，尤其是训练来源同源筛查后，检索任务的难度应当有所提高，模型的命中率理论上可能下降。然而，新版 Benchmark 的实际检索结果反而优于此前版本，与预期不一致。

这一现象目前尚无法得到充分解释。由于新旧 Benchmark 在数据抽样方式、结构域组成及筛选条件等方面存在差异，尚不能直接将性能变化归因于同源筛查。

**下一步研究方向：**

计划进一步扩大查询样本规模与数据覆盖范围，系统比较不同筛选条件、数据规模及样本分布下的检索表现，分析导致新版 Benchmark 命中率提高的潜在因素。

重点考察实验结果是否受到样本选择偏置、结构域家族频率分布、AB 家族重复程度以及训练来源同源性等因素的影响，从而明确 Benchmark 的实际难度及其评价结果的可靠性。
