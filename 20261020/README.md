# 2026年10月20日：三结构域数据探索、Training-free Benchmark 与后续计划

## 本次工作

围绕 DOMINO 向三结构域组合检索的扩展，主要完成了以下工作：

- **三结构域数据探索。** 基于 TED 数据库，统计三结构域蛋白质的分布及 CATH 共现关系，分析三结构域组合的数量、频率与数据特征，为后续实验提供数据基础。
- **三结构域 Benchmark 建立。** 围绕单结构域扩展与双结构域补全任务，构建初步检索评估方案，重点研究给定两个结构域 A、B 后检索第三个结构域 C 的问题。
- **两种 Training-free 方法。** 在不额外训练三结构域模型的条件下，探索利用现有 DOMIN 表征与兼容性评分完成三结构域检索，并建立相应的 Benchmark。
- **评价指标设计。** 基于 CATH 的 Class、Architecture、Topology、Homologous Superfamily 四级分类，设计不同粒度的检索命中指标，评估模型对自然三结构域共现关系的恢复能力。

## 后续计划

### 1. 原始数据划分复现与 MMseqs2 同源性过滤

首先明确 DOMIN 原论文训练集、验证集与测试集的具体构建及划分方法。

针对当前约 **900 万条三结构域数据**，使用 MMseqs2 与 DOMIN 原始数据集的训练集进行序列相似性比对，防止训练集泄漏，设置合理的序列一致性和覆盖度阈值，过滤潜在的高同源样本，尽可能避免训练与测试数据之间的信息泄漏。

在此基础上构建相对独立的三结构域测试集，并选取约 **1,000 个查询样本**用于后续实验。

### 2. 基于 CATH 分类体系的检索验证

在筛选后的测试集上运行 Training-free 检索方案，重点评估给定两个结构域 A、B 后检索第三个结构域 C 的效果。

基于 CATH 四级分类分别统计检索命中情况，并结合 Top-K 指标，分析不同方法在各层级上的表现。

### 3. 未观测共现组合的结构预测验证

进一步关注原始 TED 共现数据中未观测到的三结构域组合，利用检索方法筛选候选组合。

尝试使用 DOMO 生成包含目标结构域的完整蛋白质序列，再通过 AlphaFold 进行结构预测，重点观察 pLDDT 等结构置信度指标，并结合结构域恢复情况，初步评估这些新组合的结构合理性与潜在可设计性。
